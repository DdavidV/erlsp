# erlsp

Erlang language server (`server/`, escript-based) and its VS Code extension client (`client/`).

## Requirements

- Erlang/OTP 28.2
- rebar3 3.27.0
- Node.js 24.18.1

## Setup

```sh
./scripts/setup.sh
```

## Run the extension

Open this folder in VS Code and press F5 (`Run Extension`), or:

```sh
cd client && npm run compile
```
